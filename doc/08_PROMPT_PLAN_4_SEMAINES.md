# Prompt 08 — Plan minimal 4 semaines

Améliore la génération et l’affichage du plan 4 semaines dans **Athlete Compass**.

## Objectif

Le plan ne doit pas être un énorme programme générique. Il doit être un **Minimum Effective Plan** : le minimum structuré pour progresser selon le profil, le limiteur et les contraintes de l’utilisateur.

## Entrées à utiliser

Le plan doit tenir compte de :

- objectif principal ;
- profil athlétique ;
- limiteur principal ;
- scores faibles ;
- matériel disponible ;
- fréquence d’entraînement ;
- contraintes : pas de course, éviter de charger les cuisses, salle classique, séances courtes, etc.

## Structure du plan

Créer un plan sur 4 semaines avec :

- focus de la semaine ;
- 3 à 5 séances par semaine selon disponibilité ;
- type de séance ;
- durée estimée ;
- objectif ;
- exercices principaux ;
- version courte ;
- substitution si matériel absent.

## Types de séances

- Force haut du corps ;
- Force jambes ;
- Zone 2 ;
- Metcon court ;
- Hybride & Core ;
- Test / Retest ;
- Récupération active.

## Exemples selon limiteur

### Limiteur : endurance longue

Priorités :

- 1 zone 2 par semaine ;
- 1 séance rameur tempo ;
- garder force mais réduire metcons trop intenses.

### Limiteur : force relative

Priorités :

- tractions ;
- développé militaire ;
- front squat ;
- RDL ;
- carries.

### Limiteur : résistance musculaire

Priorités :

- burpees ;
- kettlebell swings ;
- fentes ;
- thrusters ;
- AMRAP court.

### Limiteur : récupération

Priorités :

- réduire intensité ;
- garder zone 2 ;
- deload ;
- mobilité ;
- sommeil.

## Plan exemple V1

### Semaine 1 — Construire la base

- Séance 1 : Force haut du corps ;
- Séance 2 : Zone 2 ;
- Séance 3 : Force jambes ;
- Séance 4 : Metcon court ;
- Séance 5 : Hybride & Core.

### Semaine 2 — Ajouter de l’intensité

- Séance 1 : Full body force ;
- Séance 2 : Intervalles rameur ou course ;
- Séance 3 : Jambes hypertrophie / résistance ;
- Séance 4 : Conditioning haut du corps ;
- Séance 5 : Zone 2.

### Semaine 3 — Consolider

- Séance 1 : Force relative ;
- Séance 2 : Zone 2 longue ;
- Séance 3 : Metcon modéré ;
- Séance 4 : Core & Carries ;
- Séance 5 : Hybride long.

### Semaine 4 — Tester et ajuster

- Séance 1 : Force maintien ;
- Séance 2 : Test prioritaire ;
- Séance 3 : Zone 2 ;
- Séance 4 : Metcon court ;
- Séance 5 : Retest optionnel.

## UX attendue

La page Plan doit contenir :

- tabs semaine 1 à 4 ;
- cartes séances ;
- tags : Force, Endurance, Conditioning, Hybride, Core, Recovery ;
- objectif de la semaine ;
- score de cohérence prévu ;
- checklist ;
- bouton “Adapter selon mon matériel”.

## Important

Ne pas donner un plan médical. Ajouter un texte :

> Adapte les charges à ton niveau. Arrête ou modifie l’exercice en cas de douleur inhabituelle.
