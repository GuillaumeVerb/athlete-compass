# Prompt 06 — Design UX premium

Améliore le design de **Athlete Compass**.

## Objectif

Donner à la webapp une apparence premium, sportive, moderne et très lisible.

## Style souhaité

- dashboard sombre premium ;
- cartes arrondies ;
- typographie forte ;
- hiérarchie visuelle claire ;
- accent color électrique mais sobre ;
- sensation “performance lab” ;
- pas de look app médicale ;
- pas de look bodybuilding cheap ;
- pas de surcharge de texte.

## Message à transmettre

La page résultat doit faire comprendre en moins de 10 secondes :

1. mon âge athlétique ;
2. mon score hybride ;
3. mon profil ;
4. mon limiteur principal ;
5. ma prochaine action.

## Améliorations attendues

### Landing page

- Hero plus fort ;
- CTA plus visible ;
- preuve sociale fictive subtile ;
- section “Comment ça marche ?” en 3 étapes ;
- section “Pas une app fitness de plus” ;
- disclaimer discret mais visible.

### Résultat gratuit

Améliorer :

- carte Athletic Age ;
- carte Hybrid Score ;
- radar chart ;
- badge profil ;
- fiabilité du score ;
- prochain test recommandé ;
- Next Best Move ;
- CTA vers rapport premium.

### Premium verrouillé

- cartes verrouillées élégantes ;
- blur subtil ;
- icône cadenas ;
- ne pas frustrer l’utilisateur ;
- montrer suffisamment de valeur sans tout donner.

### Responsive mobile

Priorité haute.

Sur mobile :

- sidebar devient bottom nav ou menu compact ;
- cartes empilées ;
- CTA sticky si pertinent ;
- formulaire simple ;
- inputs lisibles ;
- pas de tableau trop large.

## Direction visuelle

Palette :

- background : `#05070A`, `#080D12`, `#0D1117` ;
- cartes : `#111820`, `#141B24` ;
- bordures : `rgba(255,255,255,0.08)` ;
- vert néon : `#52FF72` ou proche ;
- ambre premium : `#F5B82E` ;
- texte principal : `#F4F7FA` ;
- texte secondaire : `#8B98A8`.

Radius :

- cartes : 16 à 24px ;
- boutons : 12 à 16px.

Effets :

- gradients subtils ;
- glow très discret sur CTA vert ;
- pas d’effets flashy.

## Typographie

- titres forts ;
- chiffres très visibles ;
- textes courts ;
- éviter les paragraphes trop longs dans les cartes.

## À ne pas faire

- Ne pas transformer l’app en réseau social.
- Ne pas ajouter de gamification excessive.
- Ne pas créer une interface médicale.
- Ne pas utiliser de promesses du type “rajeunis biologiquement”.

## Disclaimer à garder

Toujours afficher :

> L’âge athlétique est une estimation de performance, pas une mesure biologique ni un diagnostic médical.

## Contraintes techniques

Ne change pas la logique métier sauf si nécessaire pour l’affichage.
