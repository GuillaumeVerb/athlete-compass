# Prompt 11 — Roadmap V2 à V6

Crée une roadmap produit détaillée pour **Athlete Compass**.

## Structure attendue

Créer ou mettre à jour `ROADMAP.md`.

La roadmap doit couvrir :

- V1 — Calculateur et diagnostic ;
- V2 — Rapport premium et paiement ;
- V3 — Historique et progression 30 jours ;
- V4 — Plans adaptatifs ;
- V5 — Version coach / salle ;
- V6 — Intégrations Strava, Garmin, Apple Health, Concept2.

Pour chaque version, détaille :

- objectif produit ;
- features ;
- écrans ;
- données nécessaires ;
- complexité technique ;
- risques ;
- critères de succès ;
- métriques à suivre.

## V1 — Calculateur et diagnostic

Objectif : démontrer la valeur en moins de 10 secondes.

Features :

- profil utilisateur ;
- performances manuelles ;
- âge athlétique ;
- Hybrid Score ;
- profil ;
- limiteur principal ;
- Next Best Move ;
- fiabilité du score ;
- premium verrouillé.

Critère de succès :

- l’utilisateur comprend son résultat immédiatement ;
- il a envie de débloquer le rapport complet.

## V2 — Rapport premium et paiement

Objectif : valider que les utilisateurs paient.

Features :

- Stripe Checkout ;
- rapport complet ;
- PDF ou page privée ;
- offres 9/19/29 € ;
- confirmation email ;
- accès simple sans compte ou avec magic link.

Métriques :

- taux de clic pricing ;
- taux de conversion paiement ;
- panier moyen ;
- abandon checkout.

## V3 — Historique et progression 30 jours

Objectif : créer de la rétention.

Features :

- compte utilisateur ;
- historique des bilans ;
- évolution de l’âge athlétique ;
- évolution Hybrid Score ;
- protocole retest 30 jours ;
- comparaison avant/après.

Métriques :

- taux de retour à 30 jours ;
- nombre de tests ajoutés ;
- progression moyenne ;
- réachat / upgrade.

## V4 — Plans adaptatifs

Objectif : transformer le diagnostic en accompagnement.

Features :

- plans selon contraintes ;
- adaptation hebdomadaire ;
- feedback fatigue ;
- remplacement exercices ;
- mode “je garde mon programme actuel” ;
- mode “seulement 3 jours/semaine”.

Métriques :

- activation du plan ;
- séances cochées ;
- satisfaction ;
- progression score.

## V5 — Version coach / salle

Objectif : passer en B2B/B2B2C.

Features :

- dashboard coach ;
- créer un client ;
- générer un bilan ;
- suivre plusieurs clients ;
- export PDF brandé ;
- bibliothèque de tests ;
- notes coach.

Pricing possible :

- coach solo : 29 €/mois ;
- petite salle : 79-149 €/mois ;
- paiement par rapport généré.

## V6 — Intégrations

Objectif : réduire la saisie manuelle et augmenter la valeur.

Intégrations possibles :

- Strava ;
- Garmin ;
- Apple Health ;
- Google Fit ;
- Concept2 Logbook ;
- Whoop / Oura plus tard.

Risques :

- complexité API ;
- données hétérogènes ;
- coût de maintenance ;
- privacy.

## Ajouter aussi

Créer une section “Non-objectifs V1” :

- pas de réseau social ;
- pas de tracking complet ;
- pas de nutrition complexe ;
- pas d’IA générative obligatoire ;
- pas d’intégrations wearables.

Mettre aussi à jour le README avec un résumé court de cette roadmap.
