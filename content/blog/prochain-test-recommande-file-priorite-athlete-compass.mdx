## Réponse courte

Le **prochain test recommandé** dans **Athlete Compass** n’est pas une intuition magique : c’est une **file d’attente de saisie** (et parfois de **retest**) calculée de façon **fixe** à partir de ce que tu as **déjà** ou **pas** rempli.

1. **S’il manque** au moins un test de la liste interne de priorité → l’app te propose le **premier manquant** de cette liste (avec le **titre** du protocole standard).
2. **Si tout ce bloc prioritaire est rempli** → la logique peut basculer vers un **2 km rameur** ou un **1 km rameur** selon une règle simple : si ton pilier **cardio intense** est déjà **≥ 65** (échelle du bilan), l’app pousse plutôt le **2 km** ; sinon le **1 km** — pour **ancrer** ou **retester** un repère rameur clé.

Ça explique pourquoi le libellé peut parfois **contredire ton instinct** : l’objectif est souvent **documenter** le bilan, pas seulement confirmer ce que tu aimes déjà tester.

## File de priorité : à quoi ça ressemble concrètement ?

Sans entrer dans l’implémentation ligne par ligne, l’idée est :

- **D’abord** les **gros piliers** « moteur » et **compléments cardio** (rameur 1 km, SkiErg 500, **400 m**, **2 km** rameur, **5 km**, etc.).
- **Puis** la **profondeur** : autres distances / ergs, **hybrides** type wall ball ou chipper, **force**, **unilatéral**, **carries** (farmer, sandbag, sled), **gainage**.

L’ordre est **toujours le même** pour tout le monde : ce qui change, c’est **où tu en es** dans la liste. D’où l’analogie **file d’attente** : tu ne « passes » au suivant qu’après avoir **renseigné** (ou ignoré consciemment) ce qui précède.

## Lien avec la fiabilité

Une **fiabilité** plus haute demande en pratique **plusieurs familles** de tests — voir [fiabilité : pourquoi plusieurs tests](/blog/fiabilite-bilan-tests-pourquoi-remplir-athlete-compass). Le **prochain test** aide à **répartir** cet effort sans que tu aies à deviner « quoi remplir mardi soir ».

## Prochain test ≠ Next Best Move

| | **Prochain test** | **Next Best Move** |
| --- | --- | --- |
| **But principal** | Combler des **données** manquantes ou **retester** un pilier clé | Proposer une **action d’entraînement** liée au **limiteur** |
| **Lecture** | File **déterministe** | Synthèse **profil + limiteur** |
| **Article** | Celui-ci | [Next Best Move & plan minimal](/blog/next-best-move-plan-minimal-comprendre-athlete-compass) |

Tu peux utiliser les **deux** : la file pour **remplir** le bilan, le **Next Best Move** pour **t’entraîner** intelligemment entre deux chronos.
