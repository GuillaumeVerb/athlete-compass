## Réponse courte

Le **Next Best Move** dans **Athlete Compass**, c’est la **prochaine action** jugée **la plus rentable** pour ton **limiteur** actuel — présentée simplement : **pourquoi**, **quoi faire**, **à quelle fréquence**, **quel impact** attendu. Le **plan minimal sur 4 semaines** prolonge cette idée en **structure** (démo V1) sur la page **[Plan](/plan)** — pas un programme médical ni une obligation sans contexte.

## Next Best Move : qu’est-ce que c’est ?

Sur la page **[Résultats](/results)**, le bloc **Next Best Move** résume une **décision** :

- **Pourquoi** — lien avec ton **Hybrid Score**, ton **profil** et le **pilier** qui tire le bilan vers le bas.
- **Action** — geste concret (ex. ajouter du **Z2**, un **2 km rameur**, des **circuits reps**, du **farmer carry**… selon ce que le moteur calcule à partir de tes données).
- **Fréquence** — sur **quelques semaines**, pas à l’infini.
- **Impact attendu** — lecture **réaliste** (fiabilité, radar, retest).

C’est cohérent avec le code produit : par exemple, si le limiteur est **endurance / cardio intense**, le plan peut pousser un **2 km rameur** manquant ou une **Z2** ; si c’est la **force**, un bloc **squat + press** ; si la **résistance musculaire**, des **circuits courts** ; si le **core / carry**, **farmer + hollow** — toujours **à partir de ce que tu as saisi**.

## Lien avec le limiteur et le Hybrid Score

- Le **Hybrid Score** agrège les **piliers** pondérés par ton **objectif** — voir [Hybrid Score & limiteur](/blog/hybrid-score-limiteur-comprendre-bilan-athlete-compass).
- Le **limiteur** pointe le **pilier le plus bas** parmi les données disponibles.
- Le **Next Best Move** traduit ce signal en **action** prioritaire **avant** de disperser l’entraînement.

Le **prochain test recommandé** suit une autre logique (**file de priorité** pour les champs vides, puis **rameur** selon le niveau de **cardio intense** quand tout est déjà rempli) : détail dans [prochain test recommandé : file de priorité](/blog/prochain-test-recommande-file-priorite-athlete-compass).

## Plan minimal sur 4 semaines (démo V1)

Le **[plan 4 semaines](/plan)** propose une **semaine type** et des **objectifs** cohérents avec ton **profil** et ton limiteur : c’est un **Minimum Effective Plan** — utile pour **cadrer** sans te noyer sous les options.

Si tu stagnes : [muscu + course](/blog/stagnation-muscu-course-ne-progresse-plus).

## Ce que ce n’est pas

- **Pas** un diagnostic médical ni un avis sur une blessure.
- **Pas** une garantie de progression : sommeil, stress, technique et régularité comptent.
- **Pas** un remplacement du jugement d’un coach humain si tu en as un.
